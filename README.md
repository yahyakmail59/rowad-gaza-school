# نظام مدرسة رواد غزة الثانوية الذكي

تطبيق ويب عربي لإدارة **مدرسة رواد غزة الثانوية** يعمل محليًا باستخدام HTML وCSS وJavaScript أصلي وIndexedDB، دون أطر أو مكتبات خارجية.

الشعار الرسمي الافتراضي محفوظ محليًا في `assets/images/ruwad-gaza-school-logo.jpg`. يستطيع المدير من **الإعدادات والنسخ ← هوية المدرسة** تغيير الاسم الرسمي والمختصر والشعار والهاتف والبريد والموقع والعنوان واسم المدير وبادئة أرقام الشهادات وعبارة الشهادة. تُطبّق الهوية فورًا على شاشة الدخول والقائمة وعنوان المتصفح والشهادات، وتحفظ في IndexedDB مع النسخة الاحتياطية.

تستخدم الواجهة خط **Amiri** محليًا بأوزان 400 و700، عادي ومائل. ملفات الخط وترخيص OFL موجودة في `assets/fonts/amiri/`، لذلك لا يحتاج التطبيق إلى الاتصال بـ Google Fonts وقت التشغيل.

تم ضبط مقياس القراءة بما يناسب Amiri: النص الأساسي 18px، والنصوص الثانوية لا تقل عن 14px، والجداول 16px، مع تباعد أسطر وتباين محسّنين.

## التشغيل

يفضل تشغيله عبر خادم محلي بسيط لأن JavaScript Modules تحتاج أصل HTTP في بعض المتصفحات:

```powershell
py -m http.server 8765
```

ثم افتح `http://127.0.0.1:8765/`.

## حسابات العرض

جميع الحسابات التجريبية تستخدم كلمة المرور `Salam@123`:

| الدور | اسم المستخدم |
|---|---|
| مدير | `admin.demo` |
| مدرس | `teacher.demo` |
| طالب | `student.demo` |
| ولي أمر | `guardian.demo` |

هذه الحسابات للعرض فقط. البيانات تحفظ داخل متصفحك ويمكن إعادة ضبطها من الإعدادات.
